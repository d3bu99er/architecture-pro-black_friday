# Развёртывание системы с шардингом, репликацией и кэшированием

Ниже приведён порядок действий для запуска окружения и проверки работы механизма кэширования. Предполагается, что вспомогательные скрипты уже подготовлены.

---

* **Старт всей инфраструктуры и автоматическая конфигурация**

  ```bash
  ./run.sh
  ```

---

* **Проверка статуса кэширования через API**

  ```bash
  curl http://127.0.0.1:8080
  ```

  В ответе сервиса значение поля `cache_enabled` должно быть `true`.

---

* **Измерение времени ответа при активном кэше (выполнить несколько раз подряд)**

  ```bash
  curl -s -o /dev/null -w "Status: %{http_code}\\nTotal time: %{time_total}s\\n" http://127.0.0.1:8080/helloDoc/users
  ```

  Пример поведения:

  * первый запрос выполняется дольше;
  * последующие обращения возвращаются значительно быстрее;
  * код ответа — `200`.

---

* **Отключение кэширования для сравнения результатов**

  ```bash
  curl http://127.0.0.1:8080
  ```

  В поле `cache_enabled` должно отображаться значение `false`.

  Затем повторно выполнить измерение:

  ```bash
  curl -s -o /dev/null -w "Status: %{http_code}\\nTotal time: %{time_total}s\\n" http://127.0.0.1:8080/helloDoc/users
  ```

  В этом режиме:

  * каждый запрос обрабатывается примерно за одинаковое время;
  * ускорения при повторных вызовах не наблюдается;
  * код ответа остаётся `200`.

---

* **Завершение работы и удаление созданных томов**

  ```bash
  docker-compose down -v
  ```
